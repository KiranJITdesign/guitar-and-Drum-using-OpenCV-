# Gruitre (Separated Guitar + Drums)

This version separates the app into two entry points:

- `guitar_app.py` → 6-string guitar mode (open palm to enable)
- `drum_app.py` → drum set mode (closed palm to play hits)

## Run
### Guitar
```bat
c:\Users\soudr\OneDrive\Desktop\gruiter\.venv\Scripts\python.exe c:\Users\soudr\OneDrive\Desktop\gruiter\guitar_app.py
```

### Drums
```bat
c:\Users\soudr\OneDrive\Desktop\gruiter\.venv\Scripts\python.exe c:\Users\soudr\OneDrive\Desktop\gruiter\drum_app.py
```

## Controls
- **Guitar:** open palm to enable audio; move index finger fast to pluck 6 strings.
- **Drums:** keep palm closed; move index fast to trigger a drum hit (kick/snare/tom/hihat) based on hand height.
